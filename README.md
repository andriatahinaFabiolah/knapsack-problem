# 🎒 Knapsack — Programmation Dynamique

Aide à la prise de décision optimale sous contrainte — 
visualisation interactive de l'algorithme du sac à dos.

## 🛠 Technologies

- HTML, CSS, JavaScript (single-file app)

## ✨ Fonctionnalités

- Saisie dynamique des objets (nom, poids, valeur)
- Slider pour définir la capacité du sac
- Calcul automatique de la combinaison optimale
- Visualisation pas-à-pas du tableau de programmation dynamique
- Lecture automatique de l'algorithme
- Affichage des objets sélectionnés et stats (valeur, poids, nombre)

## 🧠 Algorithme

Programmation dynamique — résolution du problème Knapsack 0/1  
Complexité : O(n·W)

## 🚀 Démo

Ouvrir directement `knapsack_dp_5.html` dans un navigateur.
